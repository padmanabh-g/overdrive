Project Title

Overdrive Tokyo: A Real-Time AI Digital Twin of Tokyo

Tagline:
“Play inside a living city powered by real-world data.”

⸻

Problem

Open-world games simulate cities with scripted NPCs and static environments.

Real cities are dynamic.

* Weather changes every hour.
* Crowds shift based on events.
* Train delays alter commuting patterns.
* Festivals attract thousands of people.
* Emergencies completely change human behavior.

Current games cannot replicate the pulse of a real city.

⸻

Solution

OverdriveTokyo is a real-time AI city simulation that synchronizes with live Tokyo data.

Instead of scripted NPCs, hundreds of AI agents react to real-world events through live APIs.

The city evolves every minute.

⸻

Key Features

🌦 Live Weather

Using weather APIs, NPCs react naturally.

* Rain → Open umbrellas
* Heatwave → Seek indoor areas
* Snow → Walk slower
* Storm → Avoid outdoor locations

⸻

👥 Live Crowd Density

Real-time crowd data changes NPC population.

Examples:

* Shibuya Crossing becomes packed on weekends.
* Harajuku gets crowded during holidays.
* Business districts fill during rush hour.

⸻

🎉 Live Event Integration

Concerts

Fireworks

Festivals

Sports games

Anime conventions

When an event starts, thousands of AI agents move toward the venue automatically.

⸻

🚆 Railway Status

Train delay APIs influence NPC behavior.

Examples:

* Delayed Yamanote Line
* Stations become overcrowded.
* NPCs reroute to different lines.
* More taxis appear.

⸻

AI Citizens

Every NPC has a role and daily routine.

Examples:

Office Worker

* Commutes to work
* Eats lunch
* Works until evening
* Visits an izakaya
* Takes the last train home

⸻

Tourist

* Visits Asakusa
* Takes photos
* Shops in Shibuya
* Returns to hotel

⸻

Student

* Goes to school
* Meets friends
* Visits an arcade
* Returns home

⸻

Each AI agent can make decisions based on its surroundings rather than following a fixed path.

⸻

Gameplay

Players experience Tokyo exactly as it is today.

Imagine:

* Fighting through hundreds of commuters during rush hour.
* Escaping through a crowd after a concert.
* Navigating Shibuya during heavy rain.
* Completing missions while a fireworks festival causes massive congestion.

The city itself becomes part of the gameplay.

⸻

Tech Stack

* Unreal Engine 5 — Open-world environment
* Fastify (Node) — Backend
* OpenAI API — AI decision-making
* OpenWeather API — Live weather
* Tokyo Event APIs — Public event schedules
* People Flow APIs (Agoop / NTT Docomo) — Crowd density
* Railway APIs — Train delays and disruptions

⸻

MVP

* One district (Shibuya or Shinjuku)
* 100 AI citizens
* Live weather integration
* Simulated crowd-density data
* One event scenario
* Dynamic NPC routing
* Real-time dashboard showing live API inputs

⸻

Future Vision

OverdriveTokyo is more than a game.

It is a Real-Time AI Digital Twin that could be used for:

* Smart city simulations
* Disaster preparedness
* Crowd management
* Urban planning
* Tourism planning
* Event operations
* Autonomous robotics testing

⸻

Demo Scenario (3 Minutes)

1. Start in a normal weekday Tokyo.
2. Display live weather and crowd APIs.
3. Trigger heavy rain.
4. NPCs immediately change behavior and seek shelter.
5. Trigger a live event.
6. Thousands of NPCs begin moving toward the venue.
7. The player navigates through the evolving city.
8. End with the message:

“Tokyo is no longer scripted. It is alive.”

⸻

One-Line Pitch

OverdriveTokyo transforms Tokyo into a living AI-powered digital twin, where real-world weather, events, transportation, and human movement shape gameplay in real time.

## The Challenge

The "Agent Forge AI Hackathon: Tokyo Creativity" challenges builders to ship production-ready AI agents in a single day. The focus is on solving real-world problems through the lens of Tokyo and Japanese creativity.

Themes include traditional craft, design, food, fashion, music, tourism, retail, local maker culture, and workflows that power modern Japanese businesses.

The AI agents must be able to:

- Access live data and gather intelligence
- Autonomously process information and manage their own state
- Write their own code
- Run reliably in the cloud
- Be built using professional-grade tooling

**Key Requirement:** The project must be built on the provided partner stacks and deployed live by demo time.

## Team Format

Participants can form teams of **1 to 6 people**. Teams are encouraged to blend different skill sets, such as developers, designers, and business minds, to tackle ambitious projects.

## AI Stack Partners

Participants have access to premium credits and tools from the following innovation partners:

- **ai&:** A full-stack AI platform built and run in Japan, offering fast, affordable, and efficient AI using domestic GPU infrastructure.
- **Daytona:** An open-source, secure infrastructure platform providing fast, isolated, and stateful composable computers (sandboxes) for AI agents. Participants receive **$100 USD** worth of Daytona credits.
- **GMI Cloud:** A platform providing access to over 200 AI models (OpenAI, Claude, Gemini, DeepSeek, etc.) via a unified API without managing infrastructure. Participants receive **$10** in GMI Cloud credits.
- **Nosana:** Decentralized GPUs to run specialized AI models, process heavy data workloads, or host custom local models affordably.
- **Qwen Cloud:** The official platform for the Qwen model family, optimized for deep reasoning and agentic coding, processing multimodal information.
- **Qoder:** An agentic coding platform for real-world software development, featuring Expert Panel Mode and Repo Wiki for true autonomy.
